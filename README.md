# Code — Engineering Intelligent Digital Products

Welcome to the **Code** platform repository. This project is a high-performance modern web application built to showcase scalable digital infrastructure, advanced UI engineering capabilities, and seamless user experiences.

## 🚀 Overview
Functioning as both a top-tier digital portfolio and an agency landing site, this platform highlights capabilities spanning **Data Management, Web Development, SEO, and Payment Integration**. The interface is built with an extreme focus on premium aesthetics, leveraging dark modes, glassmorphism, and dynamic micro-interactions.

## ✨ Key Features
- **Premium UI / UX**: Employs high framerate CSS animations, 3D transform flip cards for team members, smooth scroll-reveal triggers, and interactive hover glow effects.
- **Dynamic Contact Form**: A glassmorphic skeleton-loading contact form connected to a custom Node.js backend (`server.js`) capable of handling incoming lead generation.
- **Live Interactive Environments**: Contains fully functional standalone mockup applications:
  - `demo-hotel.html`: A Hotel Management administrative module for handling room inventory and active check-ins.
  - `demo-school.html`: A School Management dashboard featuring interactive attendance tracking and real-time class statistics.
- **Responsive Layout**: Engineered to scale seamlessly across desktop, tablet, and mobile devices natively using modern CSS grids.

## 🛠 Tech Stack
- **Frontend**: Custom HTML5, Vanilla CSS3 (Custom Variables, Gradients, Complex Keyframes), Vanilla JavaScript (ES6+).
- **Backend & APIs**: Node.js & Express (configured in `server.js` for the `/send-email` route).
- **Typography Styles**: Google Fonts (Inter) & Fontshare (Clash Display, Deltha).

## 💻 Local Setup & Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Deepak-vash23/DNA_Stack.git
   cd DNA_Stack
   ```

2. **Start the backend server** (to enable the `/send-email` contact form functionality):
   ```bash
   node server.js
   ```
   *The server runs on `http://localhost:3000` by default. Note: You may need to configure environment variables for SMTP settings in `server.js` if you are deploying the email service.*

3. **View the website:**
   Open `index.html` locally in your browser, or start a Live Server.
